# 🎓 Student Hub

A simple and user-friendly **Student Management and Academic Hub** project designed to provide students and administrators with a centralized platform for accessing and managing academic information.

## 📌 Project Overview

**Student Hub** is a web-based student project that provides separate interfaces for students and administrators. It includes student registration and login, student profiles, assignments, dashboards, event management, and student management features.

The project is developed using **HTML, CSS, and web technologies** with a focus on a clean, simple, and easy-to-use interface.

## ✨ Features

### 👨‍🎓 Student Features
- Student registration
- Student login
- Student dashboard
- Student profile
- View/manage assignments
- Access academic information
- View college events
- FAQ section
- Contact page
- About page

### 👨‍💼 Admin Features
- Admin login
- Admin dashboard
- Manage students
- Manage college events
- View and manage student information

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Navigate through the Student Hub pages.

For the best experience, open the project using **VS Code with Live Server**.
